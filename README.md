# 👗 Fashion Landing Page

Projeto desenvolvido com o objetivo de transformar uma **prototipação de interface em uma landing page real, responsiva e funcional**.

A aplicação foi construída utilizando **React + Vite**, mantendo como prioridade a fidelidade visual ao protótipo original, incluindo tipografia, composição, cards, cores, imagens, espaçamentos e hierarquia das seções.
